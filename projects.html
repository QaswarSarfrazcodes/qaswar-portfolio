AI Face Scanner – AI-Powered Facial Analysis Mobile Application

High-Performance Cross-Platform Flutter Mobile Application

Developed a high-performance cross-platform Flutter mobile application during my internship at CSOFT Systems. The application delivers 6 core AI-powered facial analysis features, accurately translated from UI/UX designs crafted by designer Ashar Ali.

  • AI Analysis Features: Modules for Age & Gender prediction, Facial Harmony (Beauty Score), Face Shape Classification, Dual-Face Resemblance Comparison, Symmetry Analysis, and Celebrity Look-Alike matching.
  • UI/UX Implementation: Transformed high-fidelity Figma wireframes and design systems by Ashar Ali into fluid Flutter components.
  • State & Navigation: Reactive state management using Riverpod and declarative guard-protected routing with GoRouter.
  • Backend & Security: Supabase integration for OAuth & Email Auth, Postgres DB, deep links (aifacescanner://), and cloud storage.
  • Caching & Storage: Hive DB and Secure Storage for encrypted local data and offline scan history caching.
  • Monetization: Rewarded Video Ads integration (Google Mobile Ads) and premium Pro subscription paywall.

Smart Car Parking Management System

Desktop Application for Smart Car Parking Management (OOP)

Developed a full-featured Desktop Application for Smart Car Parking Management as 2nd Semester Object-Oriented Programming (OOP) course project. Built using Java Swing and Core Java, simulating real-world parking facility operations.

  • Interactive Floor Map: Visual 12-slot parking grid (A1-A6, B1-B6) with real-time status indicators (Available vs Occupied).
  • Automated Entry & Exit Gates: Instant ticket generation (e.g. TCK-1001) with live timestamps and vehicle categorization.
  • Tariff Billing Engine: Dynamic hourly rate calculation and itemized printable receipt generation at checkout.
  • Operator Portal: Secure login, registration, and operator session management.
  • Search & Analytics Dashboard: Instant ticket/vehicle lookup and real-time revenue analytics.
  • Data Persistence: Custom flat-file storage for preserving slot states, user credentials, and ticket audit logs across restarts.
