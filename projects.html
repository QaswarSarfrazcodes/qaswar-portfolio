01 ✦ Flagship mobile app 2026 · shipped

Tripline — AI travel companion

Cross-platform mobile app · Flutter Web admin console

An end-to-end travel platform that generates bespoke multi-day itineraries with Groq Llama 3.3 70B, tracks multi-currency expenses and renders interactive OpenStreetMap routes at 60fps. Designed, built and shipped solo.

03 ✦ Independent project 2026 · in development

MentorLync — Expert Consultation & AI Mentorship

Flutter mobile app (Android & iOS) · Personal learning project

A full-stack mobile platform where Seekers book paid chat, audio, and video sessions with verified Experts — backed by real-time Supabase infrastructure, ZegoCloud calling, and a Gemini-powered AI Assistant. Built entirely solo to go deep on production-grade Flutter architecture, Riverpod state management, and backend integration.

Dual-role architecture: Seekers browse and book; Experts manage availability, earnings, and requests — all in a single app with role-gated navigation.
Real-time chat with rich media: text, images, voice notes, and file attachments over Supabase Realtime WebSocket — no user contact details ever exposed.
Background-safe audio/video calling: ZegoCloud SDK with FCM high-priority push delivers a native incoming-call UI even when the app is killed (CallKit / ConnectionService).
Gemini-powered AI Assistant: free daily quota for AI mentorship queries — visually distinct from human-expert chat and upgradeable to unlimited via Pro subscription.
Session-credit economy: purchase credit packs or subscribe to Pro for discounted pricing — all deduction logic lives in Supabase Edge Functions so the client never enforces business rules.
Safety layer: user reporting with evidence attachments, independent blocking, and Supabase RLS ensuring users only ever read their own records or those of an active-session counterparty.
Flutter Dart Riverpod GoRouter Supabase Postgres RLS ZegoCloud Gemini AI FCM
