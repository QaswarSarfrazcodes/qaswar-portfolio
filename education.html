What I took from it

Four things the degree actually gave me

Design that survives change

Inheritance, composition and separation of concerns — chosen because of what the code has to do next, not because a pattern has a name.

Data modelled properly

Normalisation, indexing and query cost — the reason Tripline's schema enforces access at the row level instead of trusting the client.

What the machine is doing

Processes, memory and scheduling. Knowing this is what turns "the app feels slow" into a specific, fixable cause.

AI as a component

Enough of the principles to treat a model as one part with a latency budget and a failure mode — not a black box that always answers.
